Scope of this license file
==========================

The binaries and payload files in this directory originate from the zapret
project by bol-van and the flowseal distribution, both licensed under the
MIT License as stated above:

  - winws.exe                       compiled from the bol-van/zapret C sources
  - fake_quic.bin                   QUIC initial fake payload (renamed)
  - fake_http.bin                   HTTP/TLS fake payload variant (renamed)
  - quic_initial_sample.bin         QUIC initial sample payload (renamed)
  - tls_clienthello_large.bin       TLS client-hello sample (renamed)
  - tls_clienthello_sample.bin      TLS client-hello sample (renamed)
  - voice_udp.bin                   voice/VoIP UDP payload (renamed)
  - game_udp.bin                    gaming UDP payload (renamed)
  - stun.bin                        STUN probe payload (renamed)
  - stun2.bin                       STUN probe payload variant (renamed)
  - probe.bin                       connectivity probe packet (reused)

These files are included unmodified except for renaming, in accordance with
the MIT License. The original copyright notices are retained above.

fake_tls.bin is original to this project (a TLS client-hello payload
generated for Tarn) and is not part of the upstream distribution; it is
released under the GPL-3.0 of the Tarn project (see LICENSE at the project
root).

The per-file attribution map (renamed name -> original name -> upstream set)
is documented in ATTRIBUTION.md in this directory. The original filenames
themselves refer to specific blocked services and are intentionally not
reproduced in the shipped documentation; the rename is part of the project's
neutralization work (see the engine's deprecated-artifact list in
tarn_host.py).

The source code for winws.exe is available at:
  https://github.com/bol-van/zapret/
