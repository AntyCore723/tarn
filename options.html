Установка нативного хоста + wireproxy

Чтобы трафик РЕАЛЬНО шёл через WG, нужен wireproxy — userspace-клиент WG, который поднимает локальный SOCKS5-прокси. Без него расширение не может направлять трафик через WG.
Архитектура:
Chrome → chrome.proxy (SOCKS5) → wireproxy (127.0.0.1:1080) → WG шифрование → peer Endpoint → интернет.
Без root, без TUN, без системного VPN. Только TCP проксируется (UDP/QUIC блокируется).

Windows — установка в 1 клик

Порядок важен: сначала загрузи расширение в Chrome, затем запусти install.bat — скрипт сам найдёт ваш Extension ID.
  1. Загрузи расширение: chrome://extensions → «Режим разработчика» → «Загрузить распакованное расширение» → выбери распакованную папку.
  2. Открой попап Tarn — там будет «туннель недоступен» (native host ещё не установлен). Это нормально.
  3. Открой папку расширения и запусти install.bat двойным кликом — он установит всё сам:
    • Найдёт Python (или возьмёт встроенный)
    • Скопирует движок фильтра пакетов
    • Определит Extension ID из Chrome
    • Зарегистрирует native host в реестре
  4. Статус в попапе сменится на «доступен» САМ — без перезагрузки Chrome.
  5. Для фильтра пакетов конфиг не нужен: вкладка «Фильтр пакетов» → «Полный тест стратегий» → включи фильтр. Для туннеля: добавь .conf → Connect.
Ошибка "forbidden"? Расширение не загружено в Chrome или Extension ID изменился. Заново запусти install.bat или перезагрузи расширение.

Linux / macOS

  1. Скачай файлы установки (кнопка выше) или склонируй репозиторий
  2. Запусти в терминале: 
    chmod +x install.sh
./install.sh
  3. Подключи профиль — трафик пойдёт через WG.

Ручная установка wireproxy

Если установщик не справился, скачай wireproxy вручную:
# Linux/macOS — положи бинарник сюда:
~/.tarn-tunnel/bin/wireproxy
chmod +x ~/.tarn-tunnel/bin/wireproxy

# Скачать: https://github.com/windtf/wireproxy/releases/latest
Ограничения браузерного VPN:
  • SOCKS5 проксирует только TCP. UDP (QUIC, WebRTC) блокируется принудительно.
  • Только трафик браузера Chrome. Системный трафик и другие приложения НЕ идут через туннель.
  • Для системного VPN используйте нативный WG клиент.

Добро пожаловать в Tarn!

Это расширение умеет две вещи — и обе работают независимо:
Туннель WG
Добавь свой WG-конфиг → «Сохранить и подключить». Весь трафик Chrome пойдёт через твой сервер (локальный SOCKS5).
Фильтр пакетов (без VPN)
Открой вкладку «Фильтр пакетов» → «Включить фильтр». Расширение само подберёт рабочую стратегию (проверочные цели настраиваются в параметрах).
Как начать: 1) Открой «Фильтр пакетов» и запусти «Полный тест стратегий» (рекомендуется), затем включи фильтр. 2) Для туннеля — добавь конфиг и установи native host во вкладке «Установка».
Все конфиги и данные хранятся только локально в браузере и никуда не отправляются.
