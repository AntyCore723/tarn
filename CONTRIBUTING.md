# Contributing to Tarn

Thank you for your interest in contributing to Tarn! This document outlines
the guidelines for contributing to this project.

## Developer Certificate of Origin (DCO)

By contributing to this project, you agree that your contributions are your
original work and that you have the right to submit them under the project's
license (GPL-3.0). All commits must include a `Signed-off-by` line:

```
Signed-off-by: Your Name <your.email@example.com>
```

This can be added automatically with `git commit -s`.

See [DCO.md](DCO.md) for the full Developer Certificate of Origin text.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes with sign-off (`git commit -s -m "Add feature"`)
4. Push to your fork (`git push origin feature/your-feature`)
5. Open a Pull Request

## Code Style

- JavaScript: follow the existing style (2-space indentation, single quotes)
- Python: follow PEP 8
- All new code must include `SPDX-License-Identifier: GPL-3.0-only` header

## Reporting Bugs

- Use GitHub Issues for bug reports
- Include steps to reproduce, expected behavior, and actual behavior
- Do NOT use Issues for security vulnerabilities (see SECURITY.md)
